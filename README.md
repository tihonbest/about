# Личное портфолио

Мой сайт о проектах, технических интересах и учебных достижениях.

🌐 **Сайт:** https://tihonbest.github.io/about/

## Разделы

- **Главная** — кратко обо мне, мой путь в технологиях, достижения и проекты.
- **Проекты** — мои веб-разработки с описаниями и ссылками на рабочие версии.
- **Мероприятия** — личные события, олимпиады и инженерные конкурсы.
- **Подборка олимпиад** — отдельный список конкурсов, который можно обновлять независимо от личного календаря.

## Проекты

| Проект | Описание |
|---|---|
| [Wordglass](https://tihonbest.github.io/Wordglass/) | Тренажёр английских слов |
| [Индикатор сложности расписания](https://tihonbest.github.io/planner/) | Планирование учебной нагрузки |
| [MarkIt](https://tihonbest.github.io/markit/) | Калькулятор среднего балла |

## Технологии

- HTML, CSS и JavaScript
- Git и GitHub
- GitHub Pages для публикации

## Структура данных мероприятий

- `data.js` — мои личные события, добавляемые вручную.
- `data_ai.js` — отдельная подборка олимпиад и конкурсов.
- `events.html` и `script.js` — отображение списков на сайте.

## Разработка

Сайт развивается постепенно: новые функции добавляются только тогда, когда они действительно делают портфолио понятнее и удобнее. Исходный код открыт — можно посмотреть историю изменений и устройство проекта.
